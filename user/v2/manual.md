# KTM TBI Box V2 — Руководство пользователя

## 1. Комплектация

- Диагностический адаптер KTM TBI Box V2
- 6-пиновый диагностический кабель

## 2. Установка

Подключите устройство к 6-пиновому диагностическому разъёму мотоцикла. Разъём расположен за рулевой колонкой.

> ⚠️ Соблюдайте полярность — неправильное подключение может повредить устройство и ЭБУ.

Устройство питается от бортовой сети мотоцикла (12 В). Отдельного подключения питания не требуется.

## 3. Первое включение

При включении зажигания мотоцикла устройство автоматически:
1. Выполняет самотестирование — быстрое мигание светодиода (~0.5 сек)
2. Определяет тип ЭБУ (TBI 2024+, TPI 2020-2023, TPI 2018-2019)
3. Переходит в рабочий режим

### Индикация светодиода

Устройство имеет один зелёный светодиод, который отображает состояние системы. Состояния имеют приоритет — при одновременном наступлении нескольких событий отображается более важное.

**Приоритет состояний (от высшего к низшему):**

| Приоритет | Состояние | Как выглядит | Что делать |
|:---------:|-----------|--------------|------------|
| 1 | **Операция** | Частое мигание (100 мс) | Дождитесь завершения (переключение карты, удаление ошибок) |
| 2 | **Перегрев** | Короткие вспышки (80 мс) с паузами ~1 сек | Остановитесь, дайте двигателю остыть |
| 3 | **Сервис** | Плавные вспышки в течение 4 сек после старта | Проведите ТО, сбросьте счётчик |
| 4 | **Check Engine** | Мигание (500 мс), повторяется каждые 8 сек | Считайте ошибки через веб-интерфейс |
| 5 | **Режим OTA** | Частое мигание (200 мс) | Загрузите прошивку через браузер |
| 6 | **Диагностика** | Медленное мигание (1000 мс) | Wi-Fi активен, можно подключаться |
| 7 | **Прогрев** | Плавная пульсация (яркость нарастает ~2.5 сек) | Двигатель холодный, прогревается |
| 8 | **Норма** | Горит постоянно | Всё в порядке |

**Цвет свечения в нормальном режиме:**
- Яркий зелёный — активна «зелёная» (eco) карта ЭБУ
- Приглушённый — активна «белая» (стандартная) карта ЭБУ

## 4. Кнопка управления

Устройство имеет одну кнопку с настраиваемыми действиями.

### Доступные действия

| Действие | Что происходит |
|----------|----------------|
| Диагностический режим | Включает/выключает Wi-Fi для подключения телефона |
| Переключить карту ЭБУ | Переключает между «зелёной» и «белой» картой |
| Стереть ошибки | Удаляет все сохранённые коды ошибок из ЭБУ |
| Перезагрузка в OTA | Перезагружает устройство в режим обновления прошивки |

### Настройка кнопки

Через веб-интерфейс (Ещё → Настройки → Кнопки) можно назначить:
- **Одинарное нажатие** — по умолчанию: переключить карту ЭБУ
- **Длинное нажатие (1 сек)** — по умолчанию: стереть ошибки

## 5. Подключение к телефону

1. Включите зажигание мотоцикла
2. Дождитесь запуска устройства (кратковременное мигание светодиода)
3. Подключитесь к Wi-Fi сети `DIAGBOX-XXXXXXXXXXXX` 
4. Откройте в браузере: `192.168.11.1`

> 💡 При включённом DNS (по умолчанию выключен) можно использовать адрес `ktm.top`

Wi-Fi включается автоматически при старте и отключается через 60 секунд бездействия. Чтобы включить постоянный режим — нажмите кнопку быстро два раза подряд.

## 6. Веб-интерфейс

### Вкладки навигации

| Вкладка | Описание |
|---------|----------|
| **Панель** (Dashboard) | Основные параметры: температуры, обороты, MAP, TPS, зажигание, напряжение |
| **Датчики** | Полный список всех датчиков ЭБУ с записью данных |
| **Ошибки** (DTC) | Чтение и удаление кодов ошибок |
| **Сервис** | Сервисные интервалы |
| **Ещё** | Настройки, информация ЭБУ, калибровка |

### Панель (Dashboard)

Отображает ключевые параметры в виде карточек:
- **Температуры** — температура ОЖ и атмосферы
- **Двигатель** — обороты, состояние мощностного клапана (для TPI)
- **MAP** — давление во впуске и атмосферное
- **TPS** — положение дроссельной заслонки (угол/напряжение)
- **IA** — угол опережения зажигания
- **Бортсеть** — напряжение АКБ
- **Моточасы** — общее время работы двигателя
- **Карта ЭБУ** — переключатель активной карты

Нажатие на карточку MAP, TPS или IA открывает график в реальном времени.

Дополнительно отображаются:
- Сервисные интервалы (если настроены)
- Статус дополнительных датчиков: транспортная блокировка, датчик переворота, кнопка «Стоп»

### Датчики

Полная таблица всех параметров ЭБУ:

| Параметр | Описание |
|----------|----------|
| Обороты | RPM двигателя |
| Мощностной клапан | Положение клапана (%, только TBI) |
| ДПДЗ | Угол/напряжение/открытие дроссельной заслонки |
| Температура ОЖ | Температура охлаждающей жидкости |
| Температура атмосферы | Температура окружающего воздуха |
| MAP впуск | Давление в картере |
| MAP атмосфера | Атмосферное давление |
| УОЗ | Угол опережения зажигания |
| Бортсеть | Напряжение бортовой сети |
| Моточасы | Общие и на холостом ходу |
| MIL | Статус индикатора Check Engine |
| Блокировка | Статус транспортной блокировки |
| Датчик переворота | Состояние датчика |
| Кнопка «Стоп» | Состояние кнопки остановки |

**Функции:**
- Выбор до 3 датчиков для отображения на графике
- Запись до 6 датчиков в CSV-файл (до 5 минут)

### Ошибки (DTC)

- **Считать** — получить список ошибок из ЭБУ
- **Стереть** — удалить все ошибки

Для каждой ошибки отображается:
- Код ошибки (Pxxxx)
- Описание
- Статус: текущая / сохранённая / тест провален
- Возможные причины (при наличии)

### Сервис

Управление сервисными интервалами (до 4 интервалов):
- Создание интервала с названием и периодичностью
- Прогресс-бар использования
- Сброс после проведения обслуживания
- Удаление интервала

Устройство предупреждает о необходимости сервиса плавными вспышками светодиода при старте.

### Ещё (More)

| Раздел | Описание |
|--------|----------|
| Информация ЭБУ | VIN, версии калибровки, прошивки, серийный номер (если поддерживается)|
| Матрица моточасов | Детальные данные о наработке по режимам (если поддерживается) |
| Настройка х.х. | Установка оборотов холостого хода |
| Калибровка ДПДЗ | Установка нулевого положения дросселя (если поддерживается) |
| Настройки | Все настройки устройства |
| Перезагрузка | Перезагрузка устройства |
| Обновление прошивки | Переход в режим OTA |

## 7. Настройки

### Общие
- **Тип ЭБУ** — автоматически / TBI 2024+ / TPI 2020-2023 / TPI 2018-2019
- **Сервисные интервалы** — учитывать полные моточасы или без учёта холостого хода
- **Телеметрия** — BLE-трансляция данных (для RaceChrono и аналогичных приложений)

### Предупреждения
- **Check Engine** — отслеживание ошибок ЭБУ
- **Необходимость сервиса** — индикация просроченных интервалов
- **Перегрев** — порог срабатывания (70–140°C), по умолчанию 115°C
- **Прогрев** — порог прогрева двигателя (30–80°C), по умолчанию 50°C

### Кнопки
- **Одинарное нажатие** — диагностический режим / переключить карту / стереть ошибки / перезагрузка в OTA
- **Длинное нажатие** — диагностический режим / переключить карту / стереть ошибки / перезагрузка в OTA

### Веб-интерфейс
- **Тема** — цветовая схема: стандартная / KTM / Husqvarna / GASGAS / светлая
- **Стартовый экран** — какая вкладка открывается первой
- **Карточки Dashboard** — выбор отображаемых элементов
- **DNS** — доступ по адресу ktm.top (блокирует мобильный интернет)

## 8. Обновление прошивки

1. **Перейдите в режим OTA** одним из способов:
   - Веб-интерфейс → Ещё → Обновление прошивки
   - Назначенная кнопка (если настроено)
   
2. Светодиод начнёт быстро мигать (200 мс) — режим OTA активен

3. Подключитесь к Wi-Fi `DIAGBOX-XXXXXXXXXXXX`

4. Откройте `192.168.11.1` в браузере

5. Выберите файл прошивки (`.bin`) и нажмите **Upload**

6. Дождитесь завершения — устройство перезагрузится автоматически

> ⚠️ Не отключайте питание во время обновления!

Режим OTA автоматически завершится через 60 секунд бездействия.

## 9. Решение проблем

### Устройство не включается
- Проверьте подключение диагностического разъёма
- Убедитесь, что зажигание включено
- Проверьте предохранитель

### Не удаётся подключиться к Wi-Fi
- Поднесите телефон ближе к устройству
- Убедитесь, что выбрана правильная сеть `DIAGBOX-...`
- Перезагрузите устройство

### Веб-интерфейс не открывается
- Используйте точный адрес `192.168.11.1`
- Отключите мобильный интернет (или VPN)
- Попробуйте другой браузер

### Данные датчиков не отображаются
- Дождитесь подключения к ЭБУ (несколько секунд)
- Проверьте, что двигатель заведён или зажигание включено
- Убедитесь в правильном выборе типа ЭБУ в настройках

### Ошибка чтения DTC
- Повторите попытку через несколько секунд
- Перезагрузите устройство

### Не переключается карта ЭБУ
- Убедитесь, что ЭБУ поддерживает переключение карт

### Сброс к заводским настройкам
Настройки → **Сбросить к заводским** (требует подтверждения)
