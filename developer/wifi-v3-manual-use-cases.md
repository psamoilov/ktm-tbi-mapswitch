# Юзкейсы: WiFi и веб (TBI Box V3), лаконичный набор

Четыре юзкейса по **намерению пользователя**. Разбор состояний, таймингов и кода — в `wifi-v3-use-cases.md`.

**Акторы:** пользователь (телефон/ноутбук), устройство V3.

**Контекст:** сеть **`2TBOX-…`** (12 символов после префикса), **без пароля**; веб — **`192.168.11.1`**.  
В «кратком» режиме после включения **QR на дисплее нет** — только выбор сети на телефоне. QR возможен в «диагностической» сессии (см. UC‑2).

---

## UC‑1. Успеть зайти в веб сразу после включения

**Намерение:** открыть настройки/диагностику, не включая отдельный режим.

| | |
|---|---|
| **Триггер** | Зажигание включают, прибор загрузился. |
| **Основной поток** | Появляется **`2TBOX-…`** → пользователь подключается → открывает **`192.168.11.1`**. |
| **Иначе** | Не подключился к сети вовремя — точка сама пропала. Подключился, но не пользуется вебом — после паузы точка отключается. |
| **Результат** | Веб открыт **или** окно возможностей закрыто без ошибки пользователя. |

---

## UC‑2. Спокойно работать с вебом (диагностика + опциональные QR)

**Намерение:** не упустить момент, не спешить; пользоваться подсказками на дисплее.

| | |
|---|---|
| **Триггер** | Пользователь переводит устройство в **расширенный диагностический WiFi** (кнопка, жест при старте или особая поставка — как у вашего экземпляра). |
| **Основной поток** | Точка держится **заметно дольше**, чем в UC‑1. На дисплее по очереди может быть: **QR «подключись к WiFi»** → после подключения **QR «открой сайт»** (**`http://192.168.11.1/`**) → пользователь открыл веб — **QR убирается** и **не возвращается** до конца этой WiFi‑сессии. |
| **Иначе** | Всё то же можно сделать **без QR**: выбрать **`2TBOX-…`** вручную и ввести IP. QR иногда появляется чуть позже заставки — нормально. |
| **Результат** | Стабильный сеанс с вебом; дисплей не дублирует QR после того, как веб реально пошёл в работу. |

---

## UC‑3. Управлять WiFi с кнопки

**Намерение:** включить «длинный» WiFi, при необходимости не рвать уже установленное соединение, потом выключить.

| | |
|---|---|
| **Предусловие** | На кнопке настроены действия «диагностика / WiFi» (и при необходимости четырёхнажатие) — смотрите профиль устройства. |
| **Основной поток** | Выключено → действие **включает** диагностический WiFi. Уже работает **краткий** WiFi (как UC‑1) → **то же** действие **переводит в длинный** без обрыва связи телефона с точкой. **Длинный** уже активен → **то же** действие **выключает** WiFi. |
| **Результат** | Предсказуемый цикл: по необходимости два шага до полного выключения, если начинали с краткой сессии. |

---

## UC‑4. Открыть веб по запоминающемуся имени

**Намерение:** не вводить IP, если в настройках включён DNS‑режим.

| | |
|---|---|
| **Предусловие** | В веб‑настройках **включён** доступ через **`ktm.top`**. Пользователь в сети **`2TBOX-…`**. |
| **Основной поток** | В браузере — **`ktm.top`** (или с `http://`) → тот же интерфейс, что по **`192.168.11.1`**. |
| **Иначе** | Мобильный интернет на телефоне в этой сети может пропасть — ожидаемо. На дисплее в QR по-прежнему может быть **IP**, а не имя — нормально. |
| **Результат** | Веб открыт по имени. |
