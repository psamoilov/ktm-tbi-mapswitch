# Заметки к релизам прошивки

Один файл на версию: `<version>.json`, где `<version>` — ровно то, что лежит в
`SOFTWARE_VERSION` (`include/config/Config.h`).

```json
{
  "ru": "Добавлено\n— поддержка TPI 20+\n\nИсправлено\n— не читались ошибки на TPI",
  "en": "Added\n— TPI 20+ support\n\nFixed\n— DTCs were not read on TPI"
}
```

Что важно:

- **Обе локали обязательны.** Приложение показывает текст на своей локали; если
  нужной нет, подставляется вторая — но человек тогда читает не на своём языке.
- **Текст простой.** Никакого markdown: приложение выводит его как есть, вместе
  с переносами строк. Списки — тире в начале строки.
- **Пишется до публикации.** `scripts/publish_firmware.py` берёт этот файл сам,
  если не задан `--notes-file`; файла нет — предупредит и опубликует запись с
  `notes: null`, и «что нового» в приложении окажется пустым.
- **Задним числом тоже можно.** Завести файл для уже опубликованной версии и
  прогнать `python3 scripts/publish_firmware.py --regenerate` — заметки
  подставятся в существующие записи каталога.

Подробный человеческий журнал изменений живёт отдельно, в `docs/CHANGELOG.md`:
он для сайта и полный, а здесь — короткая выжимка для экрана телефона.
